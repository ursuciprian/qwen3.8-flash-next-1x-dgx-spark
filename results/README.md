# Results index

Every single-Spark (TP=1) measurement, arm and verdict in this repo, newest first. Ground truth for the serving
numbers is the top-level [`README.md`](../README.md); this file is the index, not a second source of numbers. Until
2026-10-08 this work lived in [qwen3.8-flash-next-dgx-spark-tp-2](https://github.com/ursuciprian/qwen3.8-flash-next-dgx-spark-tp-2),
whose [results index](https://github.com/ursuciprian/qwen3.8-flash-next-dgx-spark-tp-2/blob/main/results/README.md)
keeps the 2× builds, the DP=2 runs and the shared history.

Workload tags: **[count]** counting ("list the numbers from 1 to 300", T=0, thinking off), **[task]** llama-benchy
`--prompt-mode task` (agent coding turn, 2048 new prompt tokens, up to 512 out, thinking on), **[copy]** copy-heavy
decode (1-8 concurrent copy tasks from a shared cached prefix), **[lib]** llm-inference-bench 0.7.6 (30 s sustained
decode per cell at 0/16K/64K context). Full definitions: [docs/BENCHMARKS.md](../docs/BENCHMARKS.md).
